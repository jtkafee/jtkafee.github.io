# 重點消息#

美伊衝突升級荷姆茲危機，布蘭特油價飆破90美元#

美伊衝突螺旋升級，美軍連日空襲伊朗報復官兵死傷，伊朗隨即警告將封鎖全球航運咽喉「荷姆茲海峽」，並已發生多起油輪爆炸。此地緣地獄直接推升布蘭特原油價格衝破每桶90美元。原油與能源大漲重燃全球停滯性通膨危機，美債殖利率隨之飆升，並迫使歐洲與英國央行緊盯中東局勢，重新權衡降息政策。

AI估值重估引發科技股拋售，市場驚呼OpenAI恐迎雷曼時刻#

市場質疑AI龐大資本支出的變現能力，半導體與科技股遭遇猛烈去槓桿拋售，費半指數重挫陷入熊市，美股基金出現淨流出。專家警告，面臨巨額虧損與訴訟夾擊的OpenAI若倒下，將引爆科技板塊的連鎖崩潰與「雷曼時刻」。與此同時，中國月之暗面（Kimi K3）亦因算力嚴重短缺暫停新用戶訂閱，印證算力瓶頸與資金退潮正同步重創AI市場信心。

川普12.5%新關稅倒數，避險資金推升日圓探40年新低#

川普全球關稅重拳即將對60國加徵12.5%新關稅，地緣政治風險與貿易戰陰霾驅使資金湧向美元避險。美元指數在亞洲盤急升，日圓探至40年新低。儘管日本散戶大舉做空美元押注日圓干預，但美債殖利率維持高位，非美貨幣匯率全面承壓。此外，德法領袖亦指責人民幣匯率低估、壓低出口價，歐中貿易逆差與摩擦持續擴大。

黃仁勳點名記憶體已成AI發展最大瓶頸，SK集團會長崔泰源更示警，記憶體高價恐引發「晶片通膨」並傷及終端市場。在先進製程產能吃緊下，SLC NAND等晶片與銅箔基板（CCL）漲勢未歇。雖然這有利於美光、台勝科、聯茂等上游台廠相關供應鏈在修正潮中搶抓算力需求，但也導致手機、PC等終端市場下半年的復甦路徑更顯艱辛。

策略思維#

面對當前的準滯脹與高度不確定性，老練的投資人通常會採取以下配置防線或進場邏輯：

  1. 防禦性配置優先：將資金轉向具有防禦性特質的產業，如公用事業、民生必需品、醫療保健等，這些產業受經濟週期波動影響較小，並通常有穩定的股息。
  2. 擁抱實體資產與價值型股票：增加對原物料（如石油、黃金等貴金屬）相關資產的配置，以對沖通膨風險。同時，選擇具有穩定獲利、低估值、高現金流的價值型公司，而非高成長但高估值的科技股。
  3. 提高現金部位：在市場波動加劇、不確定性升高時，保持較高的現金比重，不僅能降低風險，也能在市場深度修正時抓住更具吸引力的進場機會。
  4. 逢高減碼風險資產：尤其對於前期漲幅過大、估值偏高的科技或AI概念股，利用盤中反彈進行減碼，降低整體投資組合的風險敞口。
  5. 戰略性部署美元資產：考慮到地緣政治風險與貿易戰對非美貨幣的衝擊，持有部分美元資產作為避險工具，或是投資與美元掛鉤的固定收益產品。
  6. 密切關注總經數據與政策轉向：不輕易抄底，等待通膨出現明確降溫跡象，或主要央行政策方向明確轉向寬鬆時，再逐步考慮重新配置成長型資產。
